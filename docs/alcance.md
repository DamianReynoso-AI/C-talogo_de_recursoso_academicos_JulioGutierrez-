# Alcance del proyecto

Este documento describe las funcionalidades que podría incluir una versión futura del sistema Catálogo de Recursos Académicos.

## Funcionalidades futuras

1. **Registro de recursos**: permitir agregar nuevos recursos académicos (libros, artículos, videos, sitios web, herramientas) indicando título, tipo, tema y autor.
2. **Búsqueda y filtrado**: consultar los recursos almacenados filtrando por tipo, tema, nivel o autor/fuente.
3. **Edición y eliminación**: modificar o eliminar recursos existentes en el catálogo.
4. **Exportación de reportes**: generar listados o reportes en distintos formatos (CSV, PDF) con los recursos disponibles según ciertos criterios.
5. **Integración con APIs externas**: consultar automáticamente metadatos de recursos (por ejemplo, información de libros o artículos) mediante servicios externos.
